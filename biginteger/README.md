## Класс BigInteger

Необходимо реализовать класс `BigInteger` для работы с длинными целыми числами. Класс должен поддерживать следующие операции и возможности:

- **Арифметические операции**:
  - Сложение, вычитание, умножение, деление, остаток по модулю, работающие аналогично операциям с типом `int`.
  - Составное присваивание для этих операций (`+=`, `-=`, `*=`, `/=`, `%=`).
  - Деление должно выполняться за время не более чем `O(n²)`, где `n` — длина числа.

- **Унарные операции**:
  - Унарный минус (`-`).
  - Префиксный и постфиксный инкремент (`++x`, `x++`) и декремент (`--x`, `x--`).
  - Префиксные инкремент и декремент должны работать за `O(1)` в среднем.

- **Операторы сравнения**:
  - `==`, `!=`, `<`, `>`, `<=`, `>=`.
  - Опционально: реализация оператора `<=>` (как в C++20) с выражением остальных операторов сравнения через него.

- **Ввод-вывод**:
  - Вывод в поток (`std::ostream`) и ввод из потока (`std::istream`).

- **Методы**:
  - Метод `toString()`, возвращающий строковое представление числа.

- **Конструкторы и преобразования**:
  - Конструирование из типа `int` (включая неявное преобразование, где это необходимо).
  - Неявное преобразование в `bool` для использования в условных выражениях.

- **Литералы**:
  - Поддержка литерального суффикса `bi` для создания объектов `BigInteger` (например, `123bi`).

## Класс Rational

Используя класс `BigInteger`, необходимо реализовать класс `Rational` для работы с рациональными числами произвольной точности. Рациональные числа должны представляться в виде несократимых обыкновенных дробей, где числитель и знаменатель — длинные целые числа типа `BigInteger`. Класс должен поддерживать следующие операции и возможности:

- **Конструкторы**:
  - Конструктор из `BigInteger`.
  - Конструктор из `int`.

- **Арифметические операции**:
  - Сложение, вычитание, умножение, деление.
  - Составное присваивание для этих операций (`+=`, `-=`, `*=`, `/=`).

- **Унарные операции**:
  - Унарный минус (`-`).

- **Операторы сравнения**:
  - `==`, `!=`, `<`, `>`, `<=`, `>=`.
  - Опционально: реализация оператора `<=>` (как в C++20) с выражением остальных операторов сравнения через него.

- **Методы**:
  - Метод `toString()`, возвращающий строковое представление числа в виде `[минус]числитель/знаменатель`, где числитель и знаменатель — взаимно простые числа. Если число целое, знаменатель не выводится.
  - Метод `asDecimal(size_t precision = 0)`, возвращающий строковое представление числа в виде десятичной дроби с заданным количеством знаков после запятой (`precision`).

- **Преобразования**:
  - Оператор приведения к типу `double`.
