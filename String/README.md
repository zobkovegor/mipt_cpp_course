# Реализация класса String (аналог std::string)

## Описание проекта
Реализация упрощенной версии класса `std::string` с ручным управлением памятью на C++. Проект включает все основные операции со строками без использования стандартных контейнеров.

## Требования

### Разрешенные заголовочные файлы
- `<iostream>` для ввода/вывода
- `<cstring>` для работы с C-строками
- `<algorithm>` для `std::fill` и `std::copy`

### Запрещено использовать
- Стандартные контейнеры (`std::vector`, `std::string` и др.)
- Другие заголовки стандартной библиотеки, кроме указанных

## Реализация

### Основной функционал

#### Конструкторы
- Конструктор по умолчанию
- Из C-строки (`const char*`)
- Заполняющий конструктор (`n` символов `c`)
- Копирующий конструктор

#### Операторы
- Присваивание (с проверкой самоприсваивания)
- Сравнения (`==`, `!=`, `<`, `>`, `<=`, `>=`)
- Доступа по индексу (`[]`)
- Сложения (`+`) и добавления (`+=`)
- Ввода/вывода (`<<`, `>>`)

#### Методы
- **Размеры**:
  - `size()`, `length()` - длина строки
  - `capacity()` - выделенная память
  - `empty()` - проверка на пустоту
  - `shrink_to_fit()` - оптимизация памяти

- **Доступ**:
  - `front()`, `back()` - первый/последний символ
  - `data()` - доступ к C-строке
  - `operator[]` - доступ по индексу

- **Изменения**:
  - `push_back()` - добавление символа
  - `pop_back()` - удаление символа
  - `clear()` - очистка строки
  - `substr()` - подстрока

- **Поиск**:
  - `find()`, `rfind()` - поиск подстрок

### Управление памятью
- Ручное выделение/освобождение (`new[]`/`delete[]`)
- Минимизация перевыделений
- Нуль-терминированная строка
- Эффективное копирование (`memcpy`/`std::copy`)

## Гарантии производительности
- `push_back()`: Амортизированное O(1)
- `pop_back()`: Гарантированное O(1)
- Конкатенация: Единое выделение памяти
