# Задача: сумма произведений элементов массивов с попарно различными индексами

## Условие задачи

Даны `k` массивов целых чисел, размеры которых равны `n_1, n_2, ..., n_k` соответственно. Обозначим эти массивы как `a_1, a_2, ..., a_k`. Требуется вычислить и вывести сумму всех возможных произведений вида: `a_1[i_1] * a_2[i_2] * ... * a_k[i_k]`

где индексы `(i_1, i_2, ..., i_k)` попарно различны (т.е. `i_1 ≠ i_2 ≠ ... ≠ i_k`).

### Ограничения
- Нельзя использовать стандартные контейнеры (`std::vector`, `std::list` и т.д.), кроме потоков ввода/вывода (`cin`, `cout`).
- Все массивы должны быть созданы вручную с использованием динамического выделения памяти (`new`, `delete`).
- Программа должна использовать **O(k + n_1 + n_2 + ... + n_k)** памяти. Нельзя выделять память "с запасом".
### Входные данные:
  - Размеры массивов `n_1, n_2, ..., n_k` передаются как аргументы командной строки.
  - Элементы массивов вводятся через стандартный ввод (`cin`) в порядке: сначала все элементы `a_1`, затем `a_2`, и так далее до `ak`.
