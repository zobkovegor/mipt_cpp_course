# Условие задачи: Иерархия классов для работы с геометрическими фигурами на плоскости

## Общие требования

Необходимо реализовать иерархию классов для работы с геометрическими фигурами на плоскости. Ниже описаны структура и классы, их свойства, методы и требования к функциональности.

---

## Структура Point

- **Описание**: Точка на плоскости.
- **Поля**:
  - Открытые поля `x` и `y` типа `double`.
- **Конструкция**:
  - Точку можно задать двумя числами типа `double`.
- **Операторы**:
  - Сравнение: `==` и `!=`.

---

## Класс Line

- **Описание**: Прямая на плоскости.
- **Конструкторы**:
  - По двум точкам (`Point`).
  - По двум числам: угловой коэффициент и сдвиг.
  - По точке (`Point`) и числу (угловой коэффициент).
- **Операторы**:
  - Сравнение: `==` и `!=`.

---

## Абстрактный класс Shape

- **Описание**: Базовый абстрактный класс для всех фигур.
- **Методы**:
  - `double perimeter()` — возвращает периметр фигуры.
  - `double area()` — возвращает площадь фигуры.
  - `bool operator==(const Shape& another)` — проверяет, совпадает ли эта фигура с другой как множество точек (например, треугольник `ABC` равен треугольнику `BCA`).
  - `bool isCongruentTo(const Shape& another)` — проверяет, равна ли эта фигура другой в геометрическом смысле (можно ли совместить их движением плоскости, сохраняющим расстояния).
  - `bool isSimilarTo(const Shape& another)` — проверяет, подобна ли эта фигура другой (можно ли перевести одну фигуру в другую преобразованием подобия).
  - `bool containsPoint(const Point& point)` — проверяет, находится ли точка внутри фигуры.
  - **Трансформации**:
    - `rotate(const Point& center, double angle)` — поворот на угол (в градусах, против часовой стрелки) относительно точки.
    - `reflect(const Point& center)` — симметрия относительно точки.
    - `reflect(const Line& axis)` — симметрия относительно прямой.
    - `scale(const Point& center, double coefficient)` — гомотетия с заданным коэффициентом относительно центра.
- **Примечание**: Фигуры не обязаны иметь одинаковый тип для сравнения на равенство, конгруэнтность или подобие. Сравнение должно быть корректным для любых фигур.

---

## Класс Polygon

- **Описание**: Многоугольник, наследуется от `Shape`.
- **Методы**:
  - `verticesCount()` — возвращает количество вершин.
  - `std::vector<Point> getVertices()` — возвращает вершины многоугольника без возможности их изменения.
  - `isConvex()` — проверяет, является ли многоугольник выпуклым.
- **Конструкторы**:
  - Из вектора точек-вершин (`std::vector<Point>`) в порядке обхода.
  - Из переменного числа точек, переданных через запятую (неуказанное число аргументов).
- **Ограничения**:
  - Многоугольники с самопересечениями не возникают (гарантируется в тестах).
  - Три последовательных вершины многоугольника никогда не лежат на одной прямой.

---

## Класс Ellipse

- **Описание**: Эллипс, наследуется от `Shape`.
- **Методы**:
  - `std::pair<Point, Point> focuses()` — возвращает фокусы эллипса.
  - `std::pair<Line, Line> directrices()` — возвращает пару директрис эллипса.
  - `double eccentricity()` — возвращает эксцентриситет эллипса.
  - `Point center()` — возвращает центр эллипса.
- **Конструктор**:
  - Из двух точек (`Point`) и числа типа `double` (два фокуса и сумма расстояний от точек эллипса до фокусов).

---

## Класс Circle

- **Описание**: Круг, наследуется от `Ellipse`.
- **Методы**:
  - `double radius()` — возвращает радиус круга.
- **Конструктор**:
  - Из точки (`Point`) и числа (центр и радиус).

---

## Класс Rectangle

- **Описание**: Прямоугольник, наследуется от `Polygon`.
- **Методы**:
  - `Point center()` — возвращает центр прямоугольника.
  - `std::pair<Line, Line> diagonals()` — возвращает пару диагоналей прямоугольника.
- **Конструктор**:
  - Из двух точек (`Point`) — противоположных вершин — и числа (отношение смежных сторон).
  - Из двух возможных прямоугольников выбирается тот, у которого более короткая сторона расположена по левую сторону от диагонали, если смотреть от первой заданной точки в направлении второй.

---

## Класс Square

- **Описание**: Квадрат, наследуется от `Rectangle`.
- **Методы**:
  - `Circle circumscribedCircle()` — возвращает описанную окружность.
  - `Circle inscribedCircle()` — возвращает вписанную окружность.
- **Конструктор**:
  - Из двух точек (`Point`) — противоположных вершин.

---

## Класс Triangle

- **Описание**: Треугольник, наследуется от `Polygon`.
- **Методы**:
  - `Circle circumscribedCircle()` — возвращает описанную окружность.
  - `Circle inscribedCircle()` — возвращает вписанную окружность.
  - `Point centroid()` — возвращает центр масс треугольника.
  - `Point orthocenter()` — возвращает ортоцентр треугольника.
  - `Line EulerLine()` — возвращает прямую Эйлера.
  - `Circle ninePointsCircle()` — возвращает окружность Эйлера (окружность девяти точек).
