# Требования к реализации шаблонного класса `Tuple` (аналога `std::tuple`)

## Конструкторы

### Конструктор по умолчанию
- Должен инициализировать все элементы значениями по умолчанию.
- Участвует в перегрузке только если `std::is_default_constructible<Ti>::value` верно для всех `i`.
- Должен быть `explicit`, если хотя бы один `Ti` не поддерживает copy-list-initialization из `{}`.

### Конструктор из набора аргументов соответствующих типов
- Участвует в перегрузке только если `std::is_copy_constructible<Ti>::value` верно для всех `i`.
- Должен быть `explicit`, если `std::is_convertible<const Ti&, Ti>::value` ложно хотя бы для одного `i`.

### Конструктор от универсального набора аргументов `UTypes&&... args`
- Участвует в перегрузке, если:
  - Размеры пакетов `Types` и `UTypes` совпадают.
  - Размер пакета больше 1.
  - `std::is_constructible<Ti, Ui>::value` верно для всех `i`.
- Должен быть `explicit`, если `std::is_convertible<Ti, Ui>::value` ложно хотя бы для одного `i`.

### Конструкторы от другого `Tuple<UTypes>`
- Поддерживаются версии:
  - `const Tuple<UTypes>&`
  - `Tuple<UTypes>&&`
- Инициализирует каждый элемент выражением `get<i>(std::forward<decltype(other)>(other))`.
- Участвуют в перегрузке, если:
  - Размеры пакетов `Types` и `UTypes` совпадают.
  - `std::is_constructible_v<Ti, decltype(get<i>(FWD(other)))>` верно для всех `i`.
- Если размер пакета `Types` равен 1, то дополнительные условия:
  - `std::is_convertible_v<decltype(other), T>`,
  - `std::is_constructible_v<T, decltype(other)>`,
  - `std::is_same_v<T, U>` — все должны быть `false`.
- Должны быть `explicit`, если `std::is_convertible_v<decltype(std::get<i>(FWD(other))), Ti>` ложно хотя бы для одного `i`.

### Конструкторы от `std::pair<T1, T2>`
- Поддерживаются версии:
  - `const std::pair<T1, T2>&`
  - `std::pair<T1, T2>&&`
- Для корректной работы требуется определение template deduction guides.

### Конструкторы копирования и перемещения
- **Копирующий конструктор**:
  - Должен вызывать ошибку компиляции (CE), если `std::is_copy_constructible<Ti>::value` ложно для любого `i`.
- **Перемещающий конструктор**:
  - Не участвует в перегрузке, если `std::is_move_constructible<Ti>::value` ложно для любого `i`.

## Операторы присваивания

### Копирующий оператор присваивания
- Должен вызывать ошибку компиляции (CE), если `std::is_copy_assignable<Ti>::value` ложно хотя бы для одного `i`.

### Перемещающий оператор присваивания
- Присваивает каждому элементу выражение `std::forward<Ti>(get<i>(other))`.
- Участвует в перегрузке только если `std::is_move_assignable<Ti>::value` верно для всех `i`.

### Оператор присваивания от `const tuple<UTypes...>& other`
- Участвует в перегрузке, если:
  - Размеры пакетов совпадают.
  - `std::is_assignable<Ti&, const Ui&>::value` верно для всех `i`.

### Оператор присваивания от `tuple<UTypes...>&& other`
- Участвует в перегрузке, если:
  - Размеры пакетов совпадают.
  - `std::is_assignable<Ti&, Ui&&>::value` верно для всех `i`.

### Операторы присваивания от `std::pair`
- Поддерживаются версии:
  - `const std::pair<T1, T2>&`
  - `std::pair<T1, T2>&&`

## Необязательные требования
- Не требуется поддерживать конструкторы (4), (7), (8), (11)-(12), (15)-(28) из cppreference.
- Не требуется поддерживать операторы присваивания (2), (4), (6), (8), (10), (12)-(14) из cppreference.

## Функции, не являющиеся членами класса

### `makeTuple`, `tie`, `forwardAsTuple`
- Аналоги `std::make_tuple`, `std::tie`, `std::forward_as_tuple`.

### `get` с индексом `size_t Index`
- Принимает `Tuple` и возвращает ссылку на `index`-й элемент (того же типа, что и исходная ссылка на `Tuple`).

### `get` с типом `T`
- Возвращает ссылку на элемент типа `T` (того же типа, что и исходная ссылка).
- Ошибка компиляции, если элементов типа `T` нет или их несколько.

### `tupleCat`
- Объединяет несколько кортежей в один.
- Элементы копируются (для lvalue) или перемещаются (для rvalue).
- Каждый элемент копируется/перемещается не более одного раза.

### Лексикографическое сравнение `Tuple`
- Реализация операторов сравнения (`==`, `!=`, `<`, `>`, `<=`, `>=`).
