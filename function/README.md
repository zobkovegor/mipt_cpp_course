# Требования к реализации класса Function

Этот документ описывает требования к реализации класса `Function`, упрощенного аналога `std::function` в C++.

## Общие требования
- Класс `Function` — шаблонный класс с одним аргументом: типом функции в форме `ReturnType(Args...)`.

## Поддержка вызываемых объектов
Класс `Function` должен поддерживать следующие вызываемые объекты:
- Указатели на функции в стиле C (C-style).
- Объекты с оператором `operator()` (функторы, включая лямбда-выражения).
- Результаты `std::bind`.
- Указатели на методы или поля класса.

### Требование
- Хранимый объект должен быть **копируемым** (copy-constructible).

## Методы класса `Function`

### Конструкторы
1. **Шаблонный конструктор от `F&&`** (где `F` — вызываемый тип):
   - Сохраняет объект через копирование или перемещение.
2. **Конструктор по умолчанию и от `nullptr_t`**:
   - Создают пустой объект `Function`.
3. **Конструкторы копирования и перемещения**:
   - Должны выполнять глубокое копирование/перемещение хранимого объекта.

### Оператор вызова `operator()`
- **Возвращает**: `Ret` (результат вызова).
- Использует `std::invoke` (или аналог) для корректного вызова:
  - Указателей на методы/поля.
- Должен быть **константным**, но может вызывать неконстантные методы хранимого объекта.
- Если `Function` пуст, бросает исключение `std::bad_function_call`.

### Деструктор
- Корректно уничтожает хранимый объект.

### Операторы присваивания
1. **Присваивание копированием и перемещением**:
   - Заменяют хранимый объект, уничтожая старый.
2. **Присваивание от `F&&`**:
   - Заменяют хранимый объект новым.

### Дополнительные методы
1. **`operator bool`**:
   - Проверяет, не пуст ли объект `Function`.
2. **`target()`**:
   - Возвращает `void*` (указатель в стиле C) на хранимый объект.

## Технические ограничения

### Оптимизация для малых объектов (Small Object Optimization, SOO)
- Если размер объекта ≤ 16 байт, он должен храниться на стеке (без динамического выделения памяти).
- Обязательно для:
  - Указателей на функции.
  - Пустых лямбда-выражений.

### Производительность
- Минимизировать количество разыменований при вызове `operator()`.
- **Виртуальные функции запрещены** (ключевое слово `virtual` не должно использоваться в реализации).
