# Условие задачи: Шаблонные классы Residue и Matrix

## Класс Residue

Необходимо реализовать шаблонный класс `Residue<size_t N>` для работы с кольцом вычетов по модулю `N`. Если `N` — простое число, кольцо является полем. Класс должен удовлетворять следующим требованиям:

- **Арифметические операции**:
  - Поддержка сложения, вычитания, умножения.
  - Поддержка деления, если `N` — простое число.
  - Попытка вызова деления при составном `N` должна приводить к ошибке компиляции.

- **Конструкторы и преобразования**:
  - Конструктор от `int` с вычислением остатка от деления на `N` (в математическом смысле).
  - Явное преобразование `Residue<N>` к `int`.
  - Все преобразования должны быть явными.

- **Проверка на простоту**:
  - Проверка, является ли `N` простым числом, должна выполняться на этапе компиляции.
  - Время работы проверки должно составлять `O(sqrt(N))`.

## Класс Matrix

Используя ранее реализованный класс рациональных чисел (`Rational`), необходимо реализовать шаблонный класс `Matrix` с тремя параметрами: `size_t M`, `size_t N`, `typename Field = Rational`. По умолчанию используется поле рациональных чисел, но матрицу можно создавать и над другими полями. Класс должен поддерживать следующие возможности:

- **Конструкторы**:
  - Конструктор по умолчанию создаёт матрицу `M × N`, заполненную нулями.
  - Статический метод `unityMatrix()`, возвращающий единичную матрицу (доступен только при `M == N`, иначе не компилируется).

- **Арифметические операции**:
  - Сложение и вычитание матриц с операторами `+`, `-`, `+=`, `-=`.
    - Сложение и вычитание матриц разных размеров не должно компилироваться.
  - Умножение матрицы на число типа `Field`.
  - Умножение двух матриц.
    - Попытка перемножить матрицы несоответствующих размеров должна приводить к ошибке компиляции.

- **Методы**:
  - `det()` — вычисляет определитель матрицы за `O(N³)`.
    - Доступен только для квадратных матриц (`M == N`), иначе не компилируется.
    - Поддержка определителя для колец, не являющихся полями, необязательна.
  - `transposed()` — возвращает транспонированную матрицу.
  - `rank()` — вычисляет ранг матрицы за `O(N³)`.
    - Поддержка ранга для колец, не являющихся полями, необязательна.
  - `inverted()` — возвращает обратную матрицу.
  - `invert()` — обращает текущую матрицу.
    - Обе операции доступны только для квадратных матриц (`M == N`), иначе не компилируются.
  - `trace()` — вычисляет след матрицы.
    - Доступен только для квадратных матриц (`M == N`), иначе не компилируется.
  - `getRow(unsigned)` — возвращает строку матрицы в виде `std::array`.
  - `getColumn(unsigned)` — возвращает столбец матрицы в виде `std::array`.

- **Доступ к элементам**:
  - Двойное применение оператора `[]` (например, `matrix[i][j]`) для доступа к элементам.
  - Поддержка как для константных, так и для неконстантных матриц.
  - Для неконстантных матриц элементы можно изменять через `[]`.
  - Другие способы изменения содержимого матрицы, кроме описанных, запрещены.

- **Дополнительные возможности**:
  - Допускается реализация дополнительных методов для алгебраических операций или удобства работы, если их назначение понятно по названию и сигнатуре без комментариев.
  - Для квадратных матриц размера `N` должна быть возможность объявления с использованием одного шаблонного параметра: `SquareMatrix<N>`.
