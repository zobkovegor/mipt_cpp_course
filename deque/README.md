## Постановка задачи

Ещё полгода в этом задании можно использовать `stl::vector` и `std::array`. Лучше стандартные контейнеры использовать нельзя. Недоходимо реализовать класс `Deque<T>` — циклический контейнер, работающий по принципу двусторонней очереди (`std::deque`). В отличие от стандартного `std::deque`, ваш `Deque` должен быть реализован с помощью циклического буфера.

### Основные функциональные требования

- Конструкторы:
  - Конструктор от `int` (для задания начального размера).
  - Конструктор копирования.
  - Конструктор от `int` (для задания начального размера контейнера).
- Методы `size()` — возвращает текущий размер контейнера.
- Обращение по индексу:
  - `operator[]` (без проверки выхода за границы).
  - `at` (с проверкой выхода за границы, выбрасывает исключение при выходе за пределы).
- Методы `push_back`, `pop_back`, `push_front`, `pop_front`:
  - Добавление и удаление элементов с обоих концов за амортизированное `O(1)`.
- Итераторы:
  - Должны быть реализованы типы `iterator` и `const_iterator` в стиле STL.
    - Элемент `iterator` изменяем.
    - Элемент `const_iterator` неизменяем.
  - Сравнение: `<`, `>`, `<=`, `>=`, `==`, `!=`.
  - Разность двух итераторов (итератор минус итератор).
  - Разыменование: `operator*` возвращает `T&` (для `iterator`) или `const T&` (для `const_iterator`).
  - `operator->`.
  - Конверсия `iterator` в `const_iterator` (включая неявную) разрешена, обратная — запрещена.
- Операции `push_back`, `push_front`, `pop_back`, `pop_front`:
  - Не должны инвалидировать указатели на элементы, если не удаляется сам элемент.
  - При `pop_front` и `pop_back` указатели на удалённые элементы инвалидируются.
- Итераторы:
  - Методы `begin`, `cbegin`, `end`, `cend` для получения итераторов на начало и конец.
  - Если контейнер константный, `begin` и `end` возвращают константные итераторы.
  - Декремент `end` должен возвращать итератор на последний элемент.
  - Вычитание из `end` целых чисел должно корректно работать.
- Реверс-итераторы:
  - Методы `rbegin`, `rend`, `crbegin`, `crend` для получения реверс-итераторов.
  - Всё работает аналогично обычным итераторам, но в обратном порядке.
- Методы `insert` и `erase`:
  - `insert(iterator, const T&)` — вставляет элемент перед позицией итератора.
  - `erase(iterator)` — удаляет элемент по итератору.
  - Оба метода работают за линейное время.

### Дополнительные требования

- Всё, кроме `insert` и `erase`, должно быть безопасно относительно исключений.
  - Если в конструкторе или операторе присваивания типа `T` выброшено исключение, `Deque` должен вернуться в исходное состояние и пробросить исключение выше.
- Ваш код должен быть высокопроизводительным в программе, содержащей тесты.
