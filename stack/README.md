# Реализация стека строк на C++ с ручным управлением памятью

## Условие задачи

Требуется реализовать структуру данных "стек" для хранения строк, используя только ручное управление памятью. Запрещено использовать стандартную библиотеку C++, кроме `<iostream>`. В частности, нельзя применять `std::vector`, `std::stack`, `std::string` и другие контейнеры STL. Разрешено использовать стандартную библиотеку C.

### Ограничения
- Запрещено объявлять классы и структуры (`class`, `struct`).
- Можно использовать из C++ только:
  - `<iostream>` (для ввода/вывода)
  - операторы `new`/`delete`
  - ссылки и константы
- Все строки и узлы стека должны храниться в динамической памяти.
- Не допускаются утечки памяти или неопределённое поведение (UB).

### Команды стека
Программа должна обрабатывать следующие команды:
1. **`push somestring`**  
   Добавляет строку в стек.  
   Вывод: `ok`
2. **`pop`**  
   Удаляет верхний элемент стека и выводит его значение.  
   Если стек пуст, выводит `error`.
3. **`back`**  
   Выводит значение верхнего элемента стека.  
   Если стек пуст, выводит `error`.
4. **`size`**  
   Выводит текущее количество элементов в стеке.
5. **`clear`**  
   Очищает стек.  
   Вывод: `ok`
6. **`exit`**  
   Завершает программу.  
   Вывод: `bye` (после этого программа должна завершиться)

### Требования к реализации
- Стек должен быть реализован как односвязный список.
- Каждый узел стека должен хранить:
  - Строку (выделенную динамически)
  - Указатель на следующий узел
- Все операции должны работать за O(1), кроме `clear` (O(n)).
- Память должна освобождаться корректно.
